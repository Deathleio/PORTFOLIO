# Mayank Shah — Developer Portfolio

Modern, high-performance portfolio for **Mayank Shah** (AI & Full-Stack Engineer), built with **React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion**.

## 🚀 Key Features

- ⚡ **Recruiter-Optimized**: 10-second value proposition hook, credential stats (8.13 CGPA, 91.4% YOLOv8 mAP, 97.49% RoBERTa accuracy).
- 🛠️ **Interactive Developer CLI**: Interactive terminal emulator allowing visitors to query `projects`, `skills`, `experience`, and `contact` directly.
- 🎯 **STAR Deep-Dive Case Studies**:
  - **AI Prescription Reader & Dual-Layer Audit Engine** (*FastAPI, YOLOv8, ChromaDB, Gemini Vision, React*)
  - **VeritasAI — Explainable Fake News Detection Platform** (*Python, RoBERTa, FastAPI, PostgreSQL, Render*)
- 🔍 **Strictly Verified Skills**: Core Languages, AI/ML & Vision, GenAI/RAG/NLP, Web & Frameworks, Tools & Cloud.
- 📄 **1-Click PDF Resume**: Instant download of official ATS-formatted resume (`/resume.pdf`).
- 📨 **Direct Contact Loop**: 1-click email copy with confetti feedback + direct message form.

## 🌐 1-Click Zero-Cost Cloud Deployment

### Option A: Vercel (Recommended)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Deathleio/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new) and import your `portfolio` repository.
3. Framework Preset: **Vite** (Automatically detected).
4. Click **Deploy**. Your portfolio will be live globally in ~30 seconds with automatic SSL and continuous deployment!

### Option B: Netlify
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `dist/` folder for instant deployment, or connect your GitHub repository.
